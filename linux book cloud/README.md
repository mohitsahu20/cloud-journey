# 📘 Linux Learning Book

> A story-driven journey into Linux, from first principles to thinking like a Linux engineer.

This folder contains the chapters of a Linux book that is being written alongside my Cloud & DevOps learning journey.

The goal of this book is simple:

> **Don't just learn Linux commands. Learn how Linux thinks.**

Instead of memorizing commands, every chapter focuses on building intuition through stories, mental models, practical examples, and real-world scenarios.

# 🎯 What Makes This Different?

This is **not** a command reference or a collection of notes.

The book focuses on:

* Understanding before memorization
* Strong mental models
* Story-driven explanations
* Practical command-line examples
* Real-world engineering mindset
* Learning *why* before *how*
